# Assignment 12: Automation using Selenium (Getting Data)

## 📌 Objective

The objective of this assignment is to demonstrate how to use Selenium with Python to automate a web browser and extract data from a website.

---

## 🛠️ Technologies Used

* Python 3.11
* Selenium (Python library)
* Chrome WebDriver

## ⚙️ Steps Performed

### 1. Setup Selenium

* Installed Selenium library using pip
* Downloaded and configured Chrome WebDriver

### 2. Open Website

* Automated Chrome browser using Selenium
* Navigated to the website: https://quotes.toscrape.com

### 3. Extract Data

* Located quote elements using class name
* Extracted text data from the webpage

### 4. Display Output

* Printed the extracted quotes in the terminal

---

## ▶️ Execution

Run the script using:

```bash
python main.py
```

The script prints extracted quotes in the terminal, for example:
