# Assignment 13: Network Programming in Python Using Socket: Building A Chat Application

# 💬 Chat Application using Python (Sockets + Tkinter)

## 📌 Project Overview
This project is a simple **Client-Server Chat Application** built using:
- Python Sockets (for network communication)
- Tkinter (for GUI interface)

It allows communication between a server and a client through a basic graphical interface.

---

## 🎯 Objective
The goal of this assignment is to:
- Understand **network programming in Python**
- Learn how **client-server architecture** works
- Build a basic **GUI-based chat system**

---

## 🛠️ Technologies Used
- Python 3
- Socket Programming (`socket` module)
- GUI using `tkinter`

## ⚙️ How It Works

### 🖥️ Server:
- Creates a socket
- Binds to a host and port
- Waits for client connection
- Accepts connection from client
- Sends messages to client using GUI
- Receives messages from client on button click
- Displays chat in listbox

### 💻 Client:
- Creates a socket
- Connects to the server using host and port
- Sends messages to server using GUI
- Receives messages from server
- Displays chat in listbox
- Uses Send button to send messages
- Uses Receive button to fetch messages
